## :information_source: About

❔ A quiz about agent 007, built in one week at the Next.js Immersion by [Alura](https://www.alura.com.br), supported by Vercel. The player enters a name, answers the questions with instant feedback on each alternative, and sees the score at the end. It has page animations with Framer Motion and Lottie, and can also open quizzes made by other participants through a dynamic route.

Built in 2021.

## :arrow_forward: Run

You need [Node.js](https://nodejs.org/) and [Yarn](https://yarnpkg.com/). In the project folder:

```bash
# Install dependencies
yarn

# Start the development server
yarn dev
```

> The app opens at <http://localhost:3000>.
